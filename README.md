# 대학교 시간표 자동 생성기

대학생을 위해 세 종류의 시간표를 자동으로 만들어 주는 프로그램입니다.

1. **공강 하루 만들기** — 쉬는 날(공강)이 하루 이상 있는 시간표
2. **1교시 없는 시간표** — 1교시 수업이 하나도 없는 시간표
3. **평점 높은 강의 위주** — 한도까지 채우되 평점이 높은 강의로 구성

필수 과목은 반드시 포함하고, 입력한 학점 한도를 넘지 않으며, 시간이 겹치지
않도록 자동으로 조합합니다. 강의 정보는 CSV(Excel) 파일로 주고받습니다.

---

## 빌드 방법

소스는 순수 C(C11)이며 외부 라이브러리가 없습니다. 아래 셋 중 편한 방법을
고르세요. 어느 방법이든 결과 실행 파일 이름은 `schedule`(윈도우는 `schedule.exe`)입니다.

### 방법 1 — Visual Studio 2026 : 솔루션 열기 (윈도우)

1. `schedule.sln`을 더블클릭합니다.
2. (다른 버전에서 만든 프로젝트라는 안내가 뜨면) **[확인]**을 눌러 "대상 다시
   지정"을 한 번 수행합니다. — VS가 설치된 최신 빌드 도구로 자동 맞춰 줍니다.
3. 상단에서 구성을 `Debug` 또는 `Release`, 플랫폼을 `x64`로 두고 **Ctrl+F5**
   (디버그 없이 실행) 또는 **F5**로 실행합니다.

### 방법 2 — Visual Studio 2026 : 폴더 열기 (CMake, 윈도우)

1. **파일 → 열기 → 폴더**에서 이 폴더를 엽니다.
2. VS가 `CMakeLists.txt`를 자동으로 인식해 구성합니다(잠시 기다립니다).
3. 상단 시작 항목에서 `schedule.exe`를 고르고 실행합니다.

### 방법 3 — 명령줄 (윈도우 / 맥 / 리눅스 공용)

```sh
cmake -B build
cmake --build build
```

실행 파일은 `build/`(윈도우는 `build/Debug` 또는 `build/Release`) 안에 생깁니다.

### 방법 4 — Makefile (맥 / 리눅스, gcc·clang)

```sh
make
./schedule
```

## 사용법

실행하면 메뉴가 나옵니다.

- `[3]` 샘플 CSV를 만들어 불러오면 바로 시험해 볼 수 있습니다.
- `[2]`로 직접 만든 CSV를 불러올 수 있습니다.
- `[8]`을 고르고 학점 한도(예: 18)를 입력하면 세 시간표를 한 번에 만들어
  화면에 보여 주고, **`result_schedules.csv` 파일로 저장**합니다.

### 입력 CSV 형식

첫 줄은 제목 줄이고, 한 줄에 강의 하나를 적습니다.

```csv
강의명,교수명,요일,시작교시,종료교시,학점,평점,필수여부
컴퓨터구조,김철수,월수,2,3,3,4.3,1
인공지능,윤서연,화목,1,2,3,4.8,0
```

- 요일: `월 화 수 목 금`을 이어서 적습니다. 예) `월수`, `월수금`
- 필수여부: 필수면 `1`, 선택이면 `0`

## 한글이 깨질 때 (중요)

- **CSV 파일은 반드시 UTF-8로 저장하세요.** 한국어 Excel은 기본적으로 CP949로
  저장하는 경우가 많은데, 그러면 한글이 깨집니다. Excel에서
  **"다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)"** 를 선택하면 됩니다.
  (프로그램이 UTF-8이 아닌 파일을 감지하면 안내해 줍니다.)
- 프로그램이 저장하는 `result_schedules.csv`와 샘플 파일에는 UTF-8 표식(BOM)이
  들어 있어 Excel에서 더블클릭으로 열어도 한글이 깨지지 않습니다.
- 윈도우 콘솔 화면의 한글은 프로그램이 시작할 때 자동으로 UTF-8로 맞춥니다.

> 참고: 빌드 설정에 MSVC용 `/utf-8` 옵션과 `_CRT_SECURE_NO_WARNINGS` 정의가
> 들어 있어, Visual Studio에서 별도 설정 없이 바로 빌드됩니다.
